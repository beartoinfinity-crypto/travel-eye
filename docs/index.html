✎ 如何加入新旅程？

  1. 複製下面的生成提示詞，貼給 AI，並把【】內的行程資料改成你的。
  2. 把 AI 回傳的整段 HTML 複製起來。
  3. 貼到「② 貼上完成的 HTML」，按「儲存 HTML 並加入手帳」。

首頁會自動讀取檔案裡的 trip: meta 標籤（名稱、日期、emoji），存檔後卡片立即出現。沒有 meta 也能用「＋ 新增旅程」手動登記；換裝置或清除瀏覽資料後，自訂卡片需要重新加入。

每張卡片的「移除」會先在本機隱藏（可用上方的「還原已隱藏」挽回）。若在下方貼上 GitHub token，已發布的旅程會同時從 trips.json 和 docs/ 刪除；內建旅程只能在本機隱藏。

發布到網站（GitHub）

沒有電腦專案資料夾時用這個：會先在這個分頁遮蔽日期、航班與你填的私人字詞，再直接寫入 docs/。需要一組只限 travel-eye 的 fine-grained token（Contents: Read and write）。Token 只留在這個分頁，不會儲存；卡片上的「移除」也會使用這裡輸入的 token。
